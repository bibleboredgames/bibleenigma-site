# bibleenigma.app

The website for Bible Enigma, served by GitHub Pages (custom domain in `CNAME`).

- `index.html` and `how-to-play/index.html` use `assets/site.css`, fonts in `assets/fonts/` (Literata and Libre Franklin, OFL licenses beside them) and images in `assets/img/`. No external requests.
- `privacy/`, `support/` and `style.css` are the approved pages linked from the App Store. Do not change them.
- **Studio site link:** "More from Bible Bored Games" points to `https://bibleboredgames.github.io/links/`, in the footer of `index.html` and `how-to-play/index.html` (search for `STUDIO SITE`). Change both when the studio site moves to bibleboredgames.com.
- **App Store badge:** search for `APP STORE` in `index.html` for the two places the badge goes.
- **Screenshots:** `assets/img/screen-*.webp` come from BibleDecoder `store/screenshots/ios/iphone-6.9/` and get replaced after BibleDecoder #155.
